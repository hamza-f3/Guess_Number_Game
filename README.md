# 🎮 Guess The Number Game (Advanced Pygame Edition)

An interactive and visually rich **Guess The Number** game built with **Python & Pygame**, featuring modern UI, animations, sound effects, leaderboard system, and optional **AI gesture control using OpenCV + MediaPipe**.

---

## 🚀 Features

✨ Beautiful pixel-art UI with animations  
🎵 Background music & sound effects (adjustable)  
🧠 Multiple difficulty levels:
- EASY (1–50)
- NORMAL (1–100)
- HARD (1–500)

📊 Leaderboard system (fastest time wins)  
⌨️ Keyboard input system with real-time feedback  
🎯 Smart hint system (Higher / Lower)  
🎨 Visual feedback colors:
- 🟢 Green = Correct
- 🟡 Yellow = Close
- 🔴 Red = Far

🖐️ AI Gesture Mode (optional):
- Uses webcam via OpenCV
- Hand tracking with MediaPipe
- Navigate tutorial using gestures (thumb / fist)

⚙️ Settings Menu:
- Music volume slider
- SFX volume slider
- Toggle AI mode

---

## 🧠 How the Game Works

1. Enter your name
2. Select difficulty
3. Start guessing the hidden number
4. Receive hints:
   - "TRY HIGHER"
   - "TRY LOWER"
5. Win as fast as possible to get on the leaderboard!
